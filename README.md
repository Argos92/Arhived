# Архивед

Адаптивный статический лендинг сервиса архивного поиска. HTML, CSS и JavaScript без сборки и зависимостей.

## Локальный запуск

```sh
cd /workspace/Arhived
python3 -m http.server 8000 --bind 0.0.0.0
```

Откройте сайт через доступный в вашей среде способ просмотра. Для публикации подойдёт любой статический хостинг; корневая папка содержит `index.html`.

## Форма

Анкета скачивается в текстовый файл на устройство пользователя. Сайт не отправляет и не хранит персональные данные. Для реального приёма заявок необходимо подключить обработчик и добавить сведения об операторе и обработке данных. Платежи не подключены.

## Перед коммерческим запуском

Подтвердить действительность цены 3 870 ₽ вместо 12 000 ₽ и условия акции «только сегодня», указать реальную дату окончания, согласовать состав и сроки услуги. Текущий текст акции задан заказчиком; таймер и искусственный обратный отсчёт не используются. Проверить условия использования и фактическое покрытие источников. Находки не гарантируются.

## Визуальное оформление

Редизайн по концепции «Карта семейных путей»: светлая бумага, медные маршруты, терракотовые кнопки и иллюстрация семейного отчёта. Изображения в `assets/` — художественные иллюстрации, а не реальные архивные находки. Карта декоративная и не предназначена для точного географического или исторического ориентирования.

Все ресурсы локальные; внешние шрифты и библиотеки не требуются. Используются системные Georgia и Arial. Анимация учитывает `prefers-reduced-motion`.

## Каталог источников

Блок «Источники» содержит 114 ресурсов в 11 раскрывающихся группах по [каталогу проекта ex-ussr-kinship-research](https://github.com/DenisSergeevitch/ex-ussr-kinship-research/blob/main/references/seed-sources.md), прочитанному 28 октября 2026 года. Ресурсы категории Q (в том числе смешанной B/Q) исключены. Сохранены ссылки каталога и различие между архивами, индексами и сообществами. Доступность всех внешних сайтов отдельно не проверялась; каталог не означает гарантированный доступ или проверку всех ресурсов в рамках одного заказа.
