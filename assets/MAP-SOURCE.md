# Географическая основа

`world-countries.geojson` — Natural Earth, слой Admin 0 Countries, масштаб 1:110m, public domain.

Источник: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson

Условия использования: https://www.naturalearthdata.com/about/terms-of-use/

Скачан 28 октября 2026 года. Геометрия сохранена без изменений, неиспользуемые свойства удалены (оставлено поле `name`). Границы условны, отражают выбранную версию набора, а не исторические границы на выбранный пользователем год. Используется равнопромежуточная цилиндрическая проекция; карта предназначена для наглядной схемы маршрутов.
