# Архивед

Адаптивный статический лендинг сервиса архивного поиска. HTML, CSS и JavaScript без сборки и зависимостей.

## Локальный запуск

```sh
cd /workspace/Arhived
python3 -m http.server 8000 --bind 0.0.0.0
```

Откройте сайт через доступный в вашей среде способ просмотра. Для публикации подойдёт любой статический хостинг; корневая папка содержит `index.html`.

## Форма

Анкета скачивается в текстовый файл на устройство пользователя. Сайт не отправляет и не хранит персональные данные. Для реального приёма заявок необходимо подключить обработчик и добавить сведения об операторе и обработке данных. Платежи не подключены.

## Перед коммерческим запуском

Подтвердить действительность цены 3 870 ₽ вместо 12 000 ₽ и условия акции «только сегодня», указать реальную дату окончания, согласовать состав и сроки услуги. Текущий текст акции задан заказчиком; таймер и искусственный обратный отсчёт не используются. Проверить условия использования и фактическое покрытие источников. Находки не гарантируются.

## Визуальное оформление

Редизайн по концепции «Карта семейных путей»: светлая бумага, медные маршруты, терракотовые кнопки и иллюстрация семейного отчёта. Изображения в `assets/` — художественные иллюстрации, а не реальные архивные находки. Карта декоративная и не предназначена для точного географического или исторического ориентирования.

Все ресурсы локальные; внешние шрифты и библиотеки не требуются. Используются системные Georgia и Arial. Анимация учитывает `prefers-reduced-motion`.

## Каталог источников

Блок «Источники» содержит 114 ресурсов в 11 раскрывающихся группах по [каталогу проекта ex-ussr-kinship-research](https://github.com/DenisSergeevitch/ex-ussr-kinship-research/blob/main/references/seed-sources.md), прочитанному 28 октября 2026 года. Ресурсы категории Q (в том числе смешанной B/Q) исключены. Сохранены ссылки каталога и различие между архивами, индексами и сообществами. Доступность всех внешних сайтов отдельно не проверялась; каталог не означает гарантированный доступ или проверку всех ресурсов в рамках одного заказа.

## Интерактивная семейная история

Откройте `family.html` через тот же HTTP-сервер или напрямую с диска. На лендинге есть переход «Пример истории» и кнопка «Открыть семейный архив».

Прототип не требует сборки, ключей API, внешних шрифтов или картографических запросов. Географическая подложка Natural Earth встроена прямо в HTML как SVG и не загружается отдельным запросом; происхождение и условия описаны в `assets/MAP-SOURCE.md`.

### Возможности

- Вкладки «Карта семьи» и «Семейная летопись», фильтр по человеку, подписи родственников и просмотр источника.
- Временной ползунок с точностью до года, ввод года и автоматическое воспроизведение. Метки показывают последнюю известную запись о месте; это не гарантия непрерывного проживания. До первой записи и после года смерти метка отсутствует, пройденный маршрут остаётся.
- Переезд, проживание и рождение задают географические точки. Историческое событие входит в летопись, но не меняет место проживания. Если у человека несколько записей одного года, последней считается расположенная позже в массиве `events`.
- Масштабирование кнопками, панорамирование мышью/касанием, клавишами-стрелками, масштаб клавишами +/− и Ctrl + колесо. Кнопка ⌖ показывает все точки семьи или выбранного человека.
- Книга с генеалогическим древом по связям «родитель — ребёнок»; широкое древо прокручивается внутри книги. Хронологический рассказ формируется из внесённых описаний событий и не добавляет неподтверждённых деталей. В летописи показаны все годы независимо от ползунка карты.
- Редактор семьи, добавление родственников, годов жизни, родительских связей, координат, событий, источников и статусов. Для редактирования или удаления существующих записей можно изменить экспортированный JSON и импортировать обратно.
- Локальное сохранение в браузере, импорт и экспорт JSON, новая пустая семья и восстановление демонстрации. Перед заменой данных предлагается подтверждение; при недоступности хранилища доступен экспорт. Сервера, аккаунтов, разграничения доступа и синхронизации между устройствами в прототипе нет.

### Индивидуальные данные клиента

[assets/demo-family.json](assets/demo-family.json) — полный образец с вымышленной семьёй: 6 человек, 20 событий. В редакторе есть кнопка скачивания образца. Для другого клиента импортируйте JSON такой структуры:

```json
{
  "version": 1,
  "family": {
    "title": "История семьи Петровых",
    "intro": "Вступление к семейной летописи.",
    "demo": false
  },
  "people": [
    { "id": "p1", "name": "Анна Петрова", "birth": 1900, "death": null, "parentIds": [] }
  ],
  "events": [
    {
      "id": "e1", "personId": "p1", "year": 1920,
      "type": "residence", "place": "Казань", "lat": 55.7961, "lon": 49.1064,
      "note": "Описание события по внесённому источнику.",
      "source": "Название источника, фонд, опись, дело, лист",
      "url": "", "status": "hypothesis"
    }
  ]
}
```

Допустимые `type`: `birth`, `residence`, `move`, `historical`. Статусы: `documented` (по внесённому документу, без автоматической проверки), `hypothesis`, `demo`. Даты — целые годы 1000–2100; координаты — числовые широта −90…90 и долгота −180…180. Неизвестный год смерти задаётся как `null`. Родители указываются по ID (до двух); проверяются ссылки, уникальность ID, порядок годов жизни и отсутствие циклов. Событие должно попадать в годы жизни человека. Допустимы пустая семья и родственник без географических записей.

Ограничения импорта: 1 МБ, 50 человек, 500 событий. До подтверждения замены выполняется проверка структуры; текст экранируется, ссылки допускают только HTTP(S). Импорт заменяет текущую семью в этом браузере. Для переноса между клиентами храните отдельные JSON-файлы. Реальные архивные данные пользователь вносит самостоятельно; независимое исследование прототип не выполняет.

### Проверки прототипа

Установите Node.js 18+ и зависимости для браузерных проверок (для работы сайта они не нужны):

```sh
npm ci
npx playwright install chromium
npm test
```

Если Chromium уже установлен, можно задать `CHROMIUM_PATH=/путь/к/chromium npm test`. На Linux тест автоматически использует `/usr/bin/chromium`, если он доступен. Проверка сама поднимает HTTP-сервер на свободном локальном порту и использует изолированный браузерный контекст, не меняя пользовательские данные.

Проверяются карта и перемещения по годам, маршруты, годы смерти, фильтр, масштаб/панорамирование, воспроизведение, вкладки, древо и летопись, добавление родственника и события, сохранение, экспорт/импорт, отбрасывание некорректных файлов и URL, экранирование текста, замена клиентской семьи, пустая семья и четыре ширины экрана.

### Обновление географической подложки

Исходный набор хранится в `assets/world-countries.geojson`. После его замены выполните `python3 scripts/embed-map.py` и сохраните обновлённый `family.html`. Для запуска сайта этот шаг не требуется: готовая геометрия уже встроена в страницу и работает даже при открытии по `file://` или при блокировке загрузки GeoJSON на хостинге.
